## 📌 Overview
This repository serves as a technical journal of my journey through various offensive security platforms and Capture The Flag (CTF) challenges. My goal is to document the **methodology** and **logical progression** of each compromise, rather than just capturing flags.

## 🛠️ Toolset & Skills
In these labs, I frequently utilize:
*   **Reconnaissance:** `Nmap`, `Gobuster`, `Ffuf`, `Subfinder`
*   **Web Analysis:** `Burp Suite`, `ZAP`, `Sqlmap`
*   **Exploitation:** `Metasploit`, `Netcat`, `Searchsploit`
*   **Privilege Escalation:** `LinPEAS`, `WinPEAS`, `GTFOBins`
